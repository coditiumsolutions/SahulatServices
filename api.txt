POST Provider Availability Status
--------------------------------------------------------------------------------
Local:     https://localhost:7265/api/provider-avability-status
Deployed:  https://sahulatghartak.com/api/provider-avability-status

Request Body (option 1 - separate times):
{
  "providerUid": 4,
  "isOnline": true,
  "availableFrom": "09:00",
  "availableTo": "18:00"
}

Request Body (option 2 - single timing field):
{
  "providerUid": 4,
  "isOnline": true,
  "availableTiming": "09:00 - 18:00"
}

Request Body (offline):
{
  "providerUid": 4,
  "isOnline": false
}

Notes:
- if isOnline=true, send availableFrom + availableTo OR availableTiming
- time format: HH:mm (example: 09:00 or 9:00)

Success (200):
{
  "success": true,
  "message": "Provider availability status saved successfully.",
  "data": {
    "uid": 4,
    "providerUid": 4,
    "isOnline": true,
    "availableFrom": "09:00",
    "availableTo": "18:00",
    "availableTiming": "09:00 - 18:00"
  }
}

Fail (400):
{
  "success": false,
  "message": "AvailableFrom and AvailableTo are required when provider is online.",
  "data": null
}

Fail (404):
{
  "success": false,
  "message": "Provider not found.",
  "data": null
}
